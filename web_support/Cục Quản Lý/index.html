Open the online energy analysis and simulation app. An internet connection is required.

Personal File Catalog

Catalog metadata for notes, PDFs, code, archives and audio against a 10 GB planning target. File contents are not stored.

Turn topics, transcripts and notes into animated, topic-linked knowledge graphs.

Export all systems together or separately in several formats.

A collection of 20 reference slots for online documents and resources.

Real-time intelligence dashboard using Node/Vite. Basic local mode needs no API keys. (source not installed)

 07

MiroFish

Multi-agent simulation with a Vue frontend and Python backend. Requires LLM and Zep configuration. (source not installed)

Suggested workflow

1. Explore the online energy analysis app.

2. Catalog your files and documents locally.

3. Turn notes into topic-based knowledge graphs.

4. Export all data together or by system.

Technical notes

The file catalog, graph and export screens share data locally through localStorage in this browser. File catalog entries contain metadata only, not file bytes.

PDF export uses the browser print dialog to save a PDF.

Launch World Monitor

Folder: worldmonitor

Requirements: Node.js, npm.

Commands (after installing source): npm install then npm run dev

Default URL: http://localhost:5173

Basic local mode is intended to work without API keys; advanced features may require them. Source is not installed in this checkout.

Launch MiroFish

Folder: MiroFish

Requirements: Node.js 18+, Python 3.11-3.12, uv.

Configuration: copy .env.example to .env and configure LLM_API_KEY, LLM_BASE_URL, LLM_MODEL_NAME, ZEP_API_KEY.

Commands (after installing source): npm run setup:all then npm run dev

Default URL: frontend http://localhost:3000, backend http://localhost:5001
